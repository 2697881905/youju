# 有据 · 新用户默认头像设计说明

> 方案：**据印 · 经验叠层**（当前采用）
> 品牌理念：真实经验，有据可循。

## 1. App 整体视觉风格

| 维度 | 定义 |
|------|------|
| 视觉风格 | 理性 / 可信 / 可追溯；扁平、克制、白底、单一焦点色 |
| 品牌结构 | 复刻定稿 Logo `v2-experience-stack-mosaic`：白底 + 深墨结构 + 三层经验叠层 + 琥珀高亮 |
| 主签名色 | **深墨 `#0B0F1A` / `#111827` / `#1F2937`** + **琥珀 `#FFB21A`**（唯一彩色焦点） |
| 非品牌色 | 蓝色仅作内容层焦点，**不进入头像识别体系** |
| 禁忌 | 无渐变、无阴影、无 3D、无品牌文字、无具体人物特征 |

## 2. 造型描述（据印 · 经验叠层）

在已选定的「据印」外壳内，将原本呆板的琥珀方块升级为**形象化经验叠层**，直接复刻定稿 Logo 母题：

- **白底圆盘**：与浅色应用背景呼应，复刻 Logo 白色圆角方底。
- **深墨双线方印框**（外粗 44 + 内细 10@22%）：保留你认可的「印 = 公信认证」识别。
- **三层经验叠片**（圆角矩形，微旋 -9° / +5° / -9°，呼应 Logo 叠层动势）：
  - 上层 `#1F2937`：一条真实经验。
  - 中层 `#FFB21A`：**高亮依据**——唯一彩色焦点，即「有据可循」。
  - 下层 `#111827`：经验基底。
- **去除 ✅**：去掉原核验勾，改用「叠层中琥珀被点亮」这一更形象、更贴 Logo 的语义表达。

语义读法：**真实经验层层汇聚，其中一条被高亮为可核验依据 = 有据可循**。

## 3. 配色方案

| 角色 | 色值 | 用途 |
|------|------|------|
| 白底 | `#FFFFFF` | 圆盘底色，呼应背景 |
| 深墨（主） | `#0B0F1A` | 细环 @10%、印框、下层叠片 |
| 墨主调 | `#111827` | 下层叠片、结构 |
| 墨中调 | `#1F2937` | 上层叠片 |
| 琥珀高亮 | `#FFB21A` | 中层「高亮依据」，唯一彩色焦点 |

单资产跨浅/深双主题：`ds_brand` 同源深墨在浅色背景靠 10% 细环成界，在深色背景靠白底自然高对比。

## 4. 尺寸适配

- 母版 1024×1024 矢量，无损缩放。
- 安全区：内标控在直径 ~62% 内（印框 432 / 1024）。
- ≤40px：印框细线趋隐，三层叠片 + 琥珀中层仍是可识别信号。
- 导出档位：24 / 32 / 40 / 48 / 64 / 80 / 96 / 120 / 512（含 1x/2x/3x）。

## 5. 适用场景

| 场景 | 尺寸 | 说明 |
|------|------|------|
| 信息流 / 评论列表 | 32–48px | 小图，琥珀中层保识别 |
| 消息 / 通知 | 40–48px | 同列表档 |
| 个人主页大图 | 96–120px | 印框 + 叠层细节完整呈现 |
| 深色主题 | 全档 | 白底天然高对比 |

## 6. 备选方案（未采用）

- **品牌 mosaic 缩微**：直接缩微定稿 Logo 的 mosaic（去蓝、深墨+琥珀），舍去印框，最贴 Logo 本体，但小尺寸印框识别弱。
- 两方案均满足：中性无人物、跨双主题、去蓝、禁渐变/阴影/3D。
