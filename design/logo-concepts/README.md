## 早期方向概述（已被取代）

早期阶段曾探索以「抽象开本书影 + 一个高对比蓝色焦点」为核心的书本造型 Logo：

- `v4-pageflare`：深色书页翼 + 中央蓝色阶跃翻页闪光。
- `v5-sparkfold`：蓝色翻开的书页 + 深色中央折痕 + 火花切口。
- `v6-covercorner`：深色书封 + 大幅蓝色翻页折角。

三套都用白色圆角方形底 + 深墨强调色 + 一个饱和蓝色焦点。该方向在 2026-08 被放弃，改为「有据」新方向（无书本、无字母、无汉字字形，强调「引文 + 核验点」）。

## 当前品牌方向

新 Logo 详见 [`../youju-logo-concepts/`](../youju-logo-concepts/)，主推：

- **v2-citation-anchor**（已上线）：引文括号包围蓝色核验锚点。
- 其他备选：v1-proof-frame / v3-verified-quote / signature / character / material。

新方向共同规则：白色圆角方形底、深墨色结构、单一蓝色焦点、无渐变、无阴影、无 3D 效果、无品牌文字。
