# 有据 Logo 概念稿

这一轮以「真实经验，有据可循」为核心，不使用书本、字母或汉字字形。

- `v1-proof-frame`：引文框包围蓝色核验点，强调可验证的信息。
- `v2-citation-anchor`：一对引文括号与中央锚点，强调内容的来源和依据。
- `v3-verified-quote`：引语结构内嵌核验勾，强调真实表达经过验证。

共同规则：白色圆角方形底、深墨色结构、单一蓝色焦点、无渐变、无阴影、无
3D 效果、无品牌文字。所有 SVG 均为 1024px，可用于后续导出 HarmonyOS
前景、背景、启动图与应用内标识。

本目录只提供概念稿，不替换现有应用图标资源。

## 材质方向

`material/` 是当前推荐探索。它不把像素当作图标轮廓风格，而是将像素拼贴限定
在蓝色核心表面；主结构使用平滑曲线与圆角，保证现代感与小尺寸可读性。
