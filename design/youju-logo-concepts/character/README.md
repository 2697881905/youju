# 有据品牌主视觉方向

前几轮的符号已经验证了“有据”的语义，但过于像功能图标。这一轮增加品牌资产
所需的形状记忆：分层、偏心、切角、材料拼贴和中心焦点，同时保持白底与平滑轮廓。

- `v1-source-prism`：来源标签的立体化版本，蓝色观点面、深色依据层和来源孔位。
- `v2-experience-stack`：三层经验叠层，表现多种真实经历汇聚成可参考结论。
- `v2-source-stack-plus`：`v2-experience-stack` 的增强稿。白色连续轨迹穿过三层
  经验，连接深色来源锚点与琥珀色出处标记，补足“有据”的证据链和视觉记忆点。
- `v2-evidence-weave`：在叠层方向上进一步强化的候选稿。依据轨迹以编织路径穿过
  经验层，中心改为菱形来源锚点，形成比圆形靶心更强的专属结构记忆。
- `v2-evidence-weave-refined`：将轨迹与锚点收束为同一条证据链。白线更轻，中心
  采用沿轨迹倾斜的圆角连接件，消除菱形标记独立悬置的突兀感。
- `v2-experience-stack-clean`：移除所有悬浮的轨迹与锚点，让三层经验、深色支撑和
  像素材质直接成为主视觉；适合需要更克制、图标轮廓更干净的方向。
- `v2-experience-stack-mosaic`：在干净叠层上增加更密的像素材质，并将琥珀色
  “高亮依据”嵌入中间经验层，不使用中轴轨道或悬浮锚点。
- `v4-evidence-fan`：更强调外轮廓记忆的扇形叠片版本。三层向外展开，形成“经历
  展开、依据汇聚”的动态姿态；所有细节仍位于平滑形体内部。
- `v3-evidence-core`：像素材质包裹的证据晶核，形成更强的桌面图标轮廓。

像素只出现在表面材质中；没有复古阶梯轮廓、书本、字母、渐变或复杂光效。

`v2-experience-stack-mosaic` 已定稿为“有据”图标。其前景、背景、启动图与应用内
Logo 已同步到 HarmonyOS 资源；可复现的分层 SVG 与合成预览位于 `exports/`，概念
预览位于 `png-stack-mosaic/`，包含 1024、256、64 和 32px 尺寸。
