预览说明

设计准则 · 克制清单（本原型的底线）
  • 弹性只出现在「顶卡升起」与「印章盖章」两个主角时刻，其余一律减速/柔和曲线
  • 位移错峰 ≤ 45ms；拖拽旋转 ≤ 6°；无缩放连击、无弹跳彩带、无粒子
  • 色板严格取自项目 token：暖纸底 + 褐金 + 墨色，≤3 个色族
  • 衬线负责「信服」（报头/标题/印章），正文无衬线，字距 0
  • 全部动效只动 transform / opacity，不碰布局属性
交互 → ArkUI 落点映射
  • 拖拽跟手 / 松开回弹 / 飞出 ── PanGesture 跟手 + responsiveSpringMotion；离手 springMotion(0.5,0.75)
  • 下层卡视差级联（错峰） ── 索引延迟 + springMotion 目标跟随
  • 入场仪式（报头→日期→卡升起→信息错峰） ── TransitionEffect + delay 错峰
  • 完成态印章 ── animateTo + PlayMode.Alternate 单次回弹
  • 倒计时 ── setInterval + CountRoll（数字滚动）
需要业务层配合（本期先不实现，仅预留）
  • 期数编号（No.042）与每日 09:00 上新：GET /api/daily/meta
  • 当日已读状态持久化：POST /api/daily/read（原型已用 localStorage 模拟）
  • 编辑部精选封面图源 / 文字海报
  • 跨天自动重置与连续阅读（打卡）
