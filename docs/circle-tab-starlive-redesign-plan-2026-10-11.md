# 圈子 Tab「星图 Live」重构方案

> 版本：v1.0 · 2026-10-11
> 原型：`design/circle-tab-redesign-prototype.html`（方案二 · 星图 Live，可交互、深浅色自适应）
> 状态：待评审排期

---

## 1. 背景与目标

### 1.1 问题

现圈子 Tab（星环页）被用户评价为「跟一堆快捷方式一样，毫无特点，毫无功能性，毫无创意」：

- 24 个彩色小图标散在几乎不可见的虚线环上，本质是一个**入口墙**；
- 星环不承载内容：唯一的产出是底部一张静态资料卡，用户必须跳出页面才能读到任何帖子；
- 星环视觉（白底 + 82% 透明灰虚线 + 5% 透明度星点）在白画布上接近隐形，「星空」氛围没有立起来；
- 无发现层：想加入星图上没有的圈子，无路可走（无目录、无搜索、无创建）。

### 1.2 目标

1. **从入口墙到目的地**：不进详情页就能读内容、管关注；
2. **星环本身成为功能**：特色由交互模型承载，而非皮肤；
3. **不突兀**：延续 App 现有视觉语言（白画布/品牌蓝/衬线标题），深浅色双主题完整适配；
4. **技术红线**：ArkUI 原生动画（仅 transform/opacity/rotate），禁止 WebView/Canvas 模拟；复用现有 motion token 体系。

### 1.3 一句话宣言

> **住进宇宙里：内容来找你（星子）、关系由你摆（引力）、进入即着陆（降落）。**

---

## 2. 方案总览

采用评审确认的「方案二 · 星图 Live」（方案一「引力星域」、方案三「星域双册」已评审否决，原型保留作对照）：

- **全屏星图**：星图占据标题栏以下全部空间，行星状态 = 圈子活跃度；
- **降落（LANDING）**：点行星 → 镜头以行星为原点俯冲 → 帖子流以「点灯」编舞浮现 → 起飞返回；
- **星子**：新帖/热帖化作光点亮在所属圈子行星旁，星图即实时帖子雷达；金色星子 = 每日一帖；
- **引力调节**：拖拽行星改变轨道半径 = 调整推送强度（内环强关注/中环常关注/外环轻关注），仅对已加入圈子生效；
- **深空目录**：星图 ≠ 全量圈子。星图只放「你的 + 活跃的」，长尾圈子住「探索星云」目录（搜索/分类/加入/创建）；
- **成员可视化**：已加入行星带金环；加入瞬间点亮弹跳 + 金环浮现 + 计数滚动。

**明确否决/移除的旧元素**：底部 CircleSelectionCard 资料卡（被降落页替代）、三档拖拽抽屉（被降落页替代）、星座连线（一期不做，视反馈回流）。

---

## 3. 用户旅程（闭环）

```
看图(活跃度一览) → 点星子读帖 → 点行星降落 → 降落页加入圈子
   → 拖行星调引力 → 探索星云(搜索/浏览) → 创建新星 → 星图随你生长
```

- 新用户：星图即导览，星子引导读帖，降落页转化加入；
- 老用户：星图即个人信息流雷达 + 关注管理台；
- 创作者：创建圈子 = 「在宇宙里点燃一颗新星」，创建即叙事。

## 4. 核心机制规格

### 4.1 星图底盘

| 元素 | 规格 |
|---|---|
| 轨道 | 3 条同心细弧线（浅色：墨色低透明实线；深色：微光弧线），替代现有虚线 |
| 行星 | 保留 TagIcon 彩色 SVG + 圈子名；大小 = 圈子体量（mass：大 52/中 46/小 40vp） |
| 活跃态 | 近 7 天有新帖 → 呼吸光晕（lively）；近 7 天无新帖 → 暗星（dark：42% 透明 + 去饱和） |
| 新帖角标 | 行星右上红色角标 = 未读新帖数 |
| 中心 | 用户头像（现有）+ 呼吸光环 |
| 公转 | 保留三环独立自转 + 按环拨动 + 惯性 + 行星飞心（现有手势骨架全部复用） |
| 状态规则 | **亮暗 = 活跃度（观感）；金环 = 成员身份（权限）。两维独立，四象限合法** |

### 4.2 降落（LANDING）

- 触发：单击行星；
- 编舞：星图以行星坐标为 transform-origin `scale(2.8)` + 淡出（650ms，`MotionCurves.springSoft` 同族）→ 降落页自底部滑入；
- 降落页内容：头部（分类 eyebrow / 衬线圈子名 / 简介 / **加入按钮** / 「进入完整圈子页」链接）+ 帖子流逐条「点灯」进场（90ms stagger）；无帖圈子显示空态「🌙 这颗新星还没有帖子」；
- 返回：「‹ 起飞」反向播放，星图复原；
- 语义边界：降落页 = 轻详情（预览 + 加入转化）；发帖/完整功能仍走 `CircleDetailPage`，符合「加入/退出必须明确操作」的现有原则。

### 4.3 引力调节（followWeight）

- 触发：按住行星拖动（PanGesture），行星跟手，全局自转冻结；
- 松手：半径吸附最近轨道（阻尼回弹），toast 确认「📱 手机数码 → 强关注 · 新帖必送达」；
- 档位：内环 88vp = 强关注（新帖必送达 + 信息流高权重）/ 中环 165vp = 常关注（按热度）/ 外环 238vp = 轻关注（偶尔看看）；
- **权限**：仅已加入（金环）圈子可拖。拖未加入行星 → 行星弹回原轨道 + 引导卡「加入圈子后，才能调节推送强度 → [去加入]」（转化钩子）；
- 数据：写 `followWeight`（见 §7），影响首页推荐权重与通知策略。

### 4.4 星子（实时帖子雷达）

- 触发：服务端轮询/拉取增量（一期可用进入页面时一次性拉取最新帖，二期上轮询）；
- 视觉：10vp 光点（品牌蓝脉冲），出现在所属圈子行星附近 ±60vp，上限同时 6 颗，寿命 15s；
- 交互：点星子 → 浮出预览卡（标题/作者/赞 + 「看全文」）→ 全文页（星图内 READ 模式）；金色星子 = 每日一帖（`GET /v1/posts/daily`），点击直达全文；
- 边界：单圈子同屏只亮最新 1 颗，防刷屏。

### 4.5 深空目录（探索星云）

- 入口：星图右上「✦ 探索星云」按钮；
- 结构：搜索框 + 五大分类分组列表 + 「＋ 点亮一颗新星 · 创建圈子」常驻卡；
- 搜索无结果 → 「深空里没有叫「x」的圈子，也许该由你来点亮它」+ 创建入口（发现缺口的转化设计）；
- 目录内可直接「加入」→ 关目录 → 新行星点亮挂上对应分类轨道 + 计数滚动；
- **创建圈子**：名字（≤8 字）→ 分类 → 一句话简介 → 提交 → 🌟 新星带金环挂上轨道 + 专属点亮动画；后端需新增创建接口（见 §7）。

### 4.6 加入/退出交互（与现有原则兼容）

- 加入路径：降落页按钮 / 目录卡片 / 详情页（保留）——均为明确单击 + 文案反馈；
- 加入编舞：行星 ignite 弹跳（暗→亮）+ 金环浮现 + toast「已加入」+ 顶部已加入计数滚动；
- 退出编舞：反向熄灭，金环消失；引力档位保留 30 天（期内重新加入恢复原档）；
- 未登录：沿用现有登录引导（followTag 前置校验）。

## 5. 与现有实现的关系

| 现有资产 | 处置 |
|---|---|
| `CircleOrbitCanvas.ets`（三环/行星/手势/自转/惯性/飞心） | **保留骨架，深度改造**：行星状态层（金环/活性/角标）、行星拖拽、半径吸附 |
| `CircleTab.ets`（标题栏/滚动绑定/数据流） | 保留 HdsNavigation 结构；`detailCard()` 区块移除；新增降落/目录/星子数据流 |
| `CircleSelectionCard.ets`（底部资料卡，刚重构为原生 ListItem） | **移除**（功能被降落页整体替代） |
| `CircleDetailPage` / `CircleDetailView` | 保留，作为完整圈子页；加入按钮并存 |
| motion token（springTrack/springSettle/emphasized 等） | 直接复用 |
| 沉浸材质 / 空态 / CountRoll | 复用 |

新增组件划分（建议）：

```
components/orbit/
  OrbitGalaxy.ets        // 星图底盘（由 CircleOrbitCanvas 演进）
  OrbitPlanet.ets        // 行星（状态层：金环/活性/角标/拖拽）
  OrbitLanding.ets       // 降落页（含加入按钮、帖子点灯流）
  OrbitSeedLayer.ets     // 星子层（生成/寿命/点击）
  ExploreSheet.ets       // 深空目录（搜索/分类/创建）
  GravityToast.ets       // 引力档位确认 toast
```

## 6. 深浅色适配

| 元素 | 浅色（纸上星图） | 深色（墨空星图） |
|---|---|---|
| 画布 | `ds_canvas` #FFFFFF | `ds_canvas` #121212 |
| 轨道线 | 墨色低透明实线 | 微光弧线（drop-shadow） |
| 行星面 | 白底 + 细描边 | `ds_elevated` 底 + 光晕投影 |
| 活跃光晕 | 品牌蓝 8% 系 | 品牌蓝 20% 系 |
| 金环/星座强调 | `ds_warm` #A06400 | 亮金 #D9A441 |
| 降落页/目录面板 | 白 + 毛玻璃 | `ds_elevated` + 毛玻璃 |

全部走 ds_ 资源对，零硬编码色值。

## 7. 后端改动清单

| 项 | 类型 | 说明 |
|---|---|---|
| `Tag.followWeight`（用户维度） | 新增 | 不能放 Tag 表（每用户不同）→ 新表 `UserTagPref { userId, tagName, weight(1/2/3), updatedAt }`；读：随 `listFollowedTags` 一并返回；写：`POST /v1/tags/:name/weight` |
| 未读新帖数 | 新增 | `UserTagRead { userId, tagName, lastReadAt }`；`GET /v1/tags/unread` 返回各圈未读数；进圈子/降落时写 lastReadAt |
| 圈子活跃度 | 新增 | 轻方案：按圈子聚合「近 7 天帖数」（listPosts 已可查，加聚合接口 `GET /v1/tags/activity`）；重方案（三期）：Tag 表加 `activeScore` 定时刷新 |
| 创建圈子 | 新增 | `POST /v1/tags`（name ≤8 字、category 枚举校验、防滥用限流、重名校验）；创建者自动关注 |
| 全量目录 | 改造 | `GET /v1/tags` 支持 `all=1`（含低活跃）+ `keyword` 搜索（现有 posts 搜索逻辑复用） |
| 每日一帖 | 已有 | `GET /v1/posts/daily` 直接复用 |

## 8. 分阶段计划

### 一期：骨架替换 + 降落 + 加入 + 深空目录（可独立上线）

- 星图底盘视觉重构（弧线/活性/暗星/金环/角标——角标一期可先隐藏）；
- 降落页（含加入/退出 + 点亮编舞 + 空态）；
- 移除 CircleSelectionCard；
- 深空目录（浏览/搜索/加入；创建入口一期可灰）；
- 后端：`UserTagRead`（角标可后置）、`GET /v1/tags` 改造；
- **验收**：星环页可完成「看图→降落→读帖→加入→目录发现新圈子」全流程；深浅色走查；375vp 视口无裁切。

### 二期：引力调节 + 星子

- 行星拖拽 + 半径吸附 + followWeight 读写（后端 `UserTagPref`）；
- 星子生成/寿命/预览卡/READ 全文 + 每日一帖金星子；
- 未读角标点亮；
- **验收**：引力档位变更后在首页信息流生效；星子与行星生命周期无重叠冲突；低端机帧率达标（24+ 行星 transform 动画）。

### 三期：创建圈子 + 活跃度宇宙

- `POST /v1/tags` + 创建「点亮新星」仪式 + 防滥用；
- `activeScore` 驱动星等（大小/光晕连续分级）；
- 探索点亮机制（浏览点亮暗星）视数据回流决策；
- **验收**：创建→点亮→星图生长全链路；活跃度随社区自然波动。

## 9. 风险与对策

| 风险 | 对策 |
|---|---|
| 24+ 行星持续 transform 的性能 | 行星层 transform 合帧（现引擎已 16ms/帧）；inactive 环降频；行星超 30 颗时星图只保留「你的+活跃 TopN」 |
| 拖行星手势与横滑/返回手势冲突 | 拖拽仅在行星命中区启动（命中半径 = disc+8vp）；系统返回手势优先级高于页面内 Pan |
| 降落页与 CircleDetailPage 职责重叠 | 降落页只读+加入；发帖/设置/完整功能必须进详情页；降落页头部保留显式跳转 |
| 「强关注」骚扰 | 档位语义即通知策略；强关注上限 N 个（建议 5），超出提示 |
| 创建圈子滥用 | 名称审核（敏感词）+ 单用户创建限额 + 新圈 24h 冷启动曝光保护 |
| 引导文案过多造成噪音 | 星子/引导卡均为一次性引导（记住已展示） |

## 10. 验收清单（一期）

- [ ] 深浅色下星图、降落页、目录全量走查（对比原型逐项）
- [ ] 点行星降落 / 起飞往返 10 次无状态错乱
- [ ] 加入→点亮→金环→计数滚动；退出→熄灭；数据与详情页一致
- [ ] 深空目录搜索/加入/空结果引导
- [ ] 375vp / 平台断点 / 字体放大下无裁切
- [ ] 离开 Tab 停自转、内存无泄漏（现有逻辑回归）
- [ ] 埋点：降落率、降落页加入转化率、目录打开率、创建数（为二期决策供数）
