# 「有据」每日一贴个性化推荐 — 合规与隐私风险审查（CSO）

- **审查人**：gstack-security-officer（CSO）
- **模式**：Comprehensive（合规专项，置信阈值 ≥2，复核后全部 ≥8）
- **范围**：每日一贴个性化推荐算法涉及的画像数据与埋点链路；后端 `backend/src`、`backend/prisma/schema.prisma`、前端 `entry/src/main/ets/pages/PrivacySettingsPage.ets`、`privacy-policy.html`
- **结论摘要**：功能**当前不具备上线合规条件**。存在 3 个 🔴 上架阻塞项——①无算法备案、②无「便捷关闭个性化推荐」开关、③埋点 `userId` 恒为 null 导致画像链路失效且埋点可被刷量污染。建议 **不上架**，先补齐 P0。

## 3. 《个人信息保护法》专项

| 主题 | 依据 | 结论与落地动作 |
|---|---|---|
| 告知同意 | 第14条、第17条 | 个性化推荐**属处理目的变更**，须在隐私政策**专门告知**（目的/方式/信息种类/保存期限）。画像不涉及敏感个人信息，**通常无需单独同意**，但须显著告知并提供关闭；**需法务确认**是否认定为需单独同意的场景 |
| 自动化决策说明与拒绝权 | **第24条** | ①保证透明度与结果公平公正；②**必须**提供"不针对个人特征"或**便捷拒绝方式**（对齐 R2）；③若"每日一贴"对权益有重大影响，用户**有权要求说明并拒绝仅自动化决策**——须提供人工/申诉通道 |
| 数据最小化 | 第6条 | 画像仅取"实现推荐目的最小范围"；`SearchHistory.keyword` 属敏感度较高，建议仅用**向量/分类特征**而非明文关键词建模 |
| 留存期限 | 第19条 | 行为明细建议≤6 个月，先聚合为统计特征再删除明细（见 R7） |
| 去标识化 | 第51条 | 训练/统计环节使用 `userId` → 不可逆 ID（哈希+盐）；导出/分析用**去标识化**数据集；游客埋点保持 `userId=null` |

## 4. 埋点隐私审查（已核实代码）

| 项 | 采集范围 | 问题 | 动作 |
|---|---|---|---|
| `PostEvent` | `postId`(必)、`userId`(可空)、`action`、`createdAt` | **①`userId` 恒为 null**：`/post-event` 未挂鉴权、无全局可选鉴权，`req.userId` 永无值 → "阅读历史(曝光-点击)"画像**无法按用户聚合**，功能前置阻塞。**②不校验 `postId` 存在性**：可 `POST` 任意/不存在 `postId` 刷曝光点击 → 流量造假 + 污染画像（命中算法规定第8条）。**③缺 `[userId, createdAt]` 索引**：现仅 `@@index([postId])`、`@@index([postId,action,createdAt])`；按用户取行为历史（`WHERE userId=? ORDER BY createdAt DESC`）将**全表扫描**，数据量增长后拖垮推荐离线任务 | 挂可选鉴权回填 `userId`；校验 `postId` 存在性；加防刷（独立限流/时效签名/设备指纹）；**增 `@@index([userId, createdAt])`** |
| `SearchHistory` | `userId`、`keyword`、`createdAt` | 明文关键词留存、无 TTL | 建模去明文（特征化）；定义保留期；提供清空入口（已有数据导出能力可复用） |
| 保留期 / 匿名化 | — | 均未定义 | 明细≤6 个月→聚合后删除；统计层去标识化；游客数据单独隔离、仅用于全局热度，不进个人画像 |

## 5. 未成年人保护

- **依据**：算法规定**第18条**、PIPL**第31条**（不满 14 周岁须监护人同意 + 专门处理规则）、《未成年人网络保护条例》（未成年人模式）。
- **现状**：无年龄分层、无青少年模式、无监护人同意机制。
- **动作**：①上线"未成年人模式"，未成年人**默认关闭个性化推荐**；②不得推送诱导沉迷/不良嗜好内容；③不满 14 周岁个人信息按**敏感个人信息**处理（单独同意 + 专门规则）；④推荐候选对未成年账号**强制内容安全前置**。**是否需做年龄门槛需法务确认**。

## 6. 威胁建模要点（STRIDE）

| STRIDE | 威胁场景 | 依据/现状 | 缓解 |
|---|---|---|---|
| **Spoofing** | 匿名伪造游客身份上报埋点 | 接口无鉴权 | 可选鉴权 + 时效签名 |
| **Tampering** | **伪造埋点刷量**：伪造 `postId`/高频 `expose`/`click` | 不校验 `postId`、无限流 | 校验存在性 + 防刷限流 + 异常检测 |
| **Info Disclosure** | **越权读取他人行为画像** | `GET /metrics/posts/:id/stats` 已校验作者/管理员（✅）；但推荐服务将内部读取**全站**行为 | 服务间最小权限 + 访问审计；画像接口禁外部直出 |
| **Tampering/Elevation** | **推荐位定向不当内容投放**：污染画像诱导推荐不当内容 | 候选池未前置审核 | 候选**先过 `sensitiveWordService` + 审核态**；推荐结果抽样巡检 |
| **DoS** | **埋点接口滥用**致 `PostEvent` 表膨胀/DB 压力 | 仅 `globalLimiter`，匿名接口易被打 | 独立限流/配额/批量落库/异步写 |
| **Repudiation** | 埋点/审核行为无审计 | 仅 `console.log`，无审计表 | 关键操作落结构化审计日志 |
