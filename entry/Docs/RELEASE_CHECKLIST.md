## 三、必须处理（P0，上架前）

### 1. 🔴 生产 MySQL 无定时备份（风险最高）
- 实测：服务器 `crontab -l` 无任何 mysqldump/backup 任务。
- 后果：用户账号/帖子/关注/互动数据全部在容器内 MySQL，一旦磁盘损坏/误删/容器数据卷异常，**数据不可恢复**。
- 建议：服务器配置每日 `mysqldump` + 保留 7 天 + 可选异地（COS）。

### 2. 🔴 App 图标未最终定稿
- 现状：Logo 已迭代到 v7（等轴测书/像素书/B 字标/书页对话弧）**仍为候选探索**，未拍板；长期品牌约定「蓝圆角书本图标」(~/Downloads/抠设计稿图标.png) 也未启用为新图标。
- 后果：上架必须提交最终图标（含 layered 前景/背景），当前 `layered_image` 的素材未与最终 Logo 对齐。
- 建议：先拍板最终 Logo 方向 → 我出多尺寸资源 → 更新 `background.png/foreground.png`。

### 3. 🟠 运营主体 = 网名「抹茶味的琴」
- 风险：若 AGC 审核要求隐私政策运营主体与开发者认证主体（个体工商户执照名称）一致，会被驳回追问。
- 建议：提交前在 AGC 确认开发者认证主体名称；若被驳回，把隐私页运营主体改为执照名称重新部署（1 分钟可改）。

## 四、建议处理（P1）

### 4. 上架材料准备（AGC 后台操作）
- **应用截图**：真机（XMH0224910001401）截 4~6 张主要页面（信息流/详情/发布/个人主页），华为要求竖屏。
- **应用描述/简介**：围绕"面向大众的理性内容分享社区"写 100~300 字（我起草可代写）。
- **分类/年龄分级**：社区/社交类；内容含 UGC 建议选 16+。
- **版权证明**：华为个人开发者上架通常要求软著证书或版权承诺书（确认 AGC 要求，软著办理周期 1-2 月，建议尽早启动）。

### 5. 敏感词词库扩充（合规持续项）
- 现状：22 词为最小占位（14 通用 + 6 性别对立）。
- 建议：按内容安全基线扩充到百级规模（违规/谩骂/导流/涉黄涉暴），并建立定期更新机制。

### 6. coverImage 预签名 URL 长稳优化（技术债）
- 现状：封面存 COS GET 预签名 URL（1 年过期），长期会批量失效。
- 建议：改存 object key，读取时动态生成预签名（后端已具备该能力，改动量小）。

## 五、可选/运维（P2）

- 建议：如需要官网展示，可挂到 `mindtype.cn` 根域或子路径（需 DNS + nginx 静态托管，基础设施现成）。

### 8. git 通路被 GFW 阻断
- 现状：服务器无法 `git pull`（github 被墙），依赖 tar+scp 同步。
- 建议：服务器配 git 代理/镜像（如 ghproxy 已挂、可换 `hub.fastgit` 类镜像或自建），或保持 tar 同步习惯。

- 2G 内存可用 ~970MB，三容器运行正常；建议关注 MySQL 慢查询与日志增长，必要时上 COS 冷备日志。
