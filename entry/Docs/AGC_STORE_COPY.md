## 三、应用介绍（详细描述，可直接粘贴）

```
看测评越看越不知道买什么？「有据」把一段经验拆成能追问的结构，而不是又一篇长文。

【按体裁把经验写清楚】
测评写优点与缺点，踩坑写经历与正确做法，教程拆步骤，辩论摆方案 A/B。发布时不用想标题党，按字段把事情说完整，读者一眼能找到自己要的那部分。

【结论可追问，观点能留下】
每条结论都能被追问出处；评论可标「事实补充」与证伪，正反方摆证据、读者投票。不承诺内容绝对真实，只承诺每句结论都可以被追问得动。

【圈子是一张星图】
标签按近期热度排成三环公转的宇宙，点行星降落进圈子，点星子直达某一篇。找同类经验不用翻十页。

【鸿蒙原生做的细节】
换手时操作栏跟着手走（智感握姿）；顶栏材质折射背景（沉浸光感，低版本设备自动回退自绘）；分享卡片与深链可直接打开某一篇。

【安静、干净】
无开屏广告、无信息流广告。华为账号一键登录，游客也能直接浏览，不必先注册。

【关于内容水位】
站内早期有一批官方撰写的示例内容，正在统一标注为「示例」并逐步替换为真实用户内容。真实帖子还不多，这是我们当前的实际状态。

HarmonyOS 5.0 及以上可安装。真实经验，有据可循。
```
