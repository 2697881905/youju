# 增量学习产出 · 开发文档（2026-09-16 首次全量，4 篇：.trae/documents）

## disable-hdstabs-swipe-page-switch
- 事实：HdsTabs 默认 scrollable=true，页面主体左右滑会切 Tab；Index.ets 未显式设置即继承默认；用户要求只保留底部 tabBar 点击切换。
- 决策：显式设 scrollable=false，而不是改路由结构或自定义手势拦截。
- 模式：Hds 组件「默认值即行为」——凡影响交互的开关一律显式声明，不依赖默认。

## gsap-level-interaction-animations
- 事实：项目全部走 router.pushUrl（无 Navigation），geometryTransition 跨页不可用；动画硬约束是只动 transform/opacity。
- 决策：跨页转场改用「共享动势 + 分层进入」；飘心效果不纳入，仅做弹性缩放脉冲，保持零 UI 结构改动。
- 模式：动效方案选型先查「路由形态 + 可动属性白名单」，再定技术路径。

## post-shared-transition-plan
- 事实：API 24 原生支持 sharedTransition；源页与目标页挂同一 shared id 即可自动插值；纯文字卡片无媒体不适合强行映射。
- 决策：覆盖 DailyPostDeck 与 PostCard 两个入口；无媒体卡片不挂 id，回退现页转场。
- 模式：一镜到底落地质检点=同 id、媒体区尺寸一致、返回反向缩回、无媒体回退。

## youju-frontend-design-refinement
- 事实：品牌色由蓝 #1677FF 改为纸感浅棕以贴合奶油纸底；排版向小红书/微博/微信既有惯例校准；首页刊头顶部布局不动（用户决策）。
- 决策：走「细腻精修」路线——保留暖纸感基调与已成立资产，只做细做透，不重做。
- 模式：设计评审产出的结论必须标注「依据（代码勘察/真机走查）」与「不动项」，避免后续被当成待办反复推翻。
