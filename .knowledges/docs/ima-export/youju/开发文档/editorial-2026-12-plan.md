## 三、前 3 篇的完整结构示范（照这个写，其余同构）

### #1 年末大促退货，法定时限到底几天（pitfall）

- **踩坑经历（第三人称、非亲历）**：常见说法是"7 天过了不退"，但 7 天不是所有品类都适用，起算点也不是下单日。
- **正确做法**：
  1. 先确认是否属于"七日无理由退货"适用范围（定作、鲜活易腐、拆封的音像制品/软件、报纸期刊等除外）。
  2. 起算点：签收次日。
  3. 商家自定"不支持退货"的告知，需在你购买时**显著确认**，事后加的不算。
  4. 退货商品完好标准：能保持原有品质功能、配件与商标齐全；合理拆封查验不算不完好。
- **来源**：《消费者权益保护法》第 25 条；《网络购买商品七日无理由退货暂行办法》相关条款（发布前逐条核对现行文本）。
- **可追问点**：评论里可标"事实补充"——例如某平台的实际退货入口路径。

### #2 退货前的 3 个开关（tutorial）

步骤拆解：运费谁承担（有理由 vs 无理由）→ 赠品是否需一并退回 → 时限如何计算（签收次日）。
每步给出"在哪看、看到什么算合规"。

### #3 保价承诺不兑现，5 项材料先备齐（tutorial）

步骤拆解：下单截图 → 保价条款截图 → 降价证据（同链接同规格）→ 客服沟通记录 → 申请入口与时限。
不承诺一定成功，只承诺"材料齐了才有得谈"。

## 四、发布纪律

1. **一天最多 2 篇**，宁可少不可凑；凑数会重新把首屏做烂。
2. 每篇发布前点一遍来源链接，法条或规则若已修订，以现行文本为准。
3. 每篇标题不带"我"、不带情绪词，只写"规则 + 场景"。
4. 评论区的"事实补充/证伪"标记，编辑部要有人回；不回等于机制没生效。
5. 一周复盘一次：哪 3 篇浏览最高，下一篇就沿那个体裁与场景写。
