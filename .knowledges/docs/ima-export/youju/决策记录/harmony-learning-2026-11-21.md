# 增量学习 · 2026-11-21

> 来源：本次新处理 2 篇文档（抖音宣发脚本包 2026-11-20、发现圈子重做设计 v2 2026-11-20）
> 提炼：3 项目事实 / 2 关键决策 / 1 可复用模式

## 3 条项目事实

1. **在架版本与 HEAD 严重脱节**：应用市场在架仍是 1.0.5（2026-11-03），而仓库 HEAD 与之相差 66 files / +4308 / −1348；AI 辅助创作（11-05 起）、结构化发布流改版（11-07）、收藏页 `CollectionPage.ets`、`publishExecutor.ets` 均未随 1.0.5 上架。任何"照 HEAD 录屏/宣传"都会与用户实际所见不符。
2. **发现圈子现状是"目录"非"发现"，且线上数据近乎停产**：24 个预置圈子 `active7d` 全为 false，最近一批帖子集中在 10-14~10-20（100 篇），11-16 仅 1 篇且 tags 为空；7 天/30 天窗口均抓 0 篇。`Post.genre` 实为 5 种（review/pitfall/tutorial/debate/share），而 `listCircleOverview` 的 select 未取 genre。
3. **推广漏斗已证伪"拉新即增长"**：11-15 开发者论坛帖 → 25 次落地页点击 → 0 注册增量；外部读者绝大多数是安卓/iPhone/PC，点了也装不上。359 篇在架帖中 330 篇是示例内容，真实合格帖仅 3 篇，应用市场评分仅 1 条。瓶颈是首屏无内容而非无人来。

## 2 条关键决策

1. **宣发走"共建者招募"而非"快去下载"，录制策略选方案 B（基线 worktree 先拍）**：CTA 只承诺已上架能力（应用市场搜有据、华为账号登录、发真实帖、评论/私信加入共建），不承诺邀请码/积分/打赏/置顶/AI 拆块（未发版）。先用 `git worktree` 切 `0b0fcfff` 基线录屏、本周开拍不阻塞 1.0.6，上架后只补拍受影响镜头。**理由**：诚实即信任 + 受众装不上 + 不阻塞发版；用 worktree 而非主检出 checkout，遵循 `docs/git-worktree-policy.md` 四道防线。
2. **圈子"内容构成"按篇数取样本，不用固定时间窗口**：改为全站近 600 篇候选池、按圈分桶每圈最多 50 篇，`contentMix` 与 `recentPostCount` 同源派生；`active7d` 仍走 7 天窗口，两者解耦；推荐位从"强制 active7d"改为"活跃优先 + 安静圈子补位 3 张"。**理由**：固定窗口在停产期会让构成永久归零、首屏退回目录；配套 `Post @@index([createdAt])` 与新查询同批上线。

## 1 个可复用模式 / 检查项

**「页面重构保留入口与数据一致性」五项检查清单**（发现圈子重做 v2 沉淀）：
1. 删旧面板前先逐一登记其承载的入口/链路（创建、同城、已加入），迁移而非丢弃——阶段 4 才删，阶段 3 单独逐条验收。
2. 一次性意图必须带单调递增 seq + 完整元信息（显式 class，含 creatorId/emoji/description），不可用裸布尔或只传 name，否则连续两次丢第二个、删除入口失效。
3. 派生统计口径避免固定时间窗口：停产期用"按篇数取样本 + 同源派生"，并断言各分项之和 == 总量、文案只说"近 7 天"不说"全部/累计"。
4. 平台硬约束前置：一页只能一个 `bindSheet` 生效（2026-11-19 事故）；承载文字的浮层必须 `elevated` 实色底；深色下自定义色值需真机校色不靠推测。
5. 登录门槛统一范式：未登录不能只 toast，须给出登录入口（跳 Login 页），且入口改造要覆盖全部药丸/按钮（发现 + 已加入两个落点都要验）。
